# Retired games

Gaze Constellations and Echoes of the Face were taken out of the hub because
their controls were tiring (long eye-gaze dwell with a calibration step, and
holding facial expressions on cue). The code is kept here, not loaded, so they
can be restored: move the file back to `js/games/`, fix the `../../` imports
to `../`, and add the entry back to `catalog.js` and `registry.js`.
